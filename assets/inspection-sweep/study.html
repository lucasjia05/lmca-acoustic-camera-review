Experiments

Matched inspection benchmark

Each trial asks whether one captured acoustic map puts a visible hotspot within 3° of a simulated discharge. Each healthy trial replays background alone. Candidates use the same source and background realizations sampled at their own microphone positions. All inputs are synthetic post-decimation PCM.

What a curve measures

The main sweeps and selected-design table use a separate threshold per design and background. Use the 95th percentile (higher order statistic) of the 256 healthy calibration maxima in each setting. The pooled baseline uses the identical estimator on all 3,584 calibration frames together. Both methods use the same held-out frames. Per-setting results assume that the matching background is known at scoring time. Freeze that threshold before scoring any test data. A correct localization requires the global map maximum to exceed the threshold and point within 3° of the source. A healthy frame crossing the threshold anywhere counts as a false alert. The export separately counts alerts within 3° of the designated healthy fitting.

The frequency curve averages equally over all seven received levels (−66 through −30 dBFS in 6 dB steps) and all 14 backgrounds at each frequency. The intensity curve averages equally over the frequency grid and backgrounds. Broadband bursts have a separate curve. A settings cell averages the same frequencies within one background. Percentages describe this chosen set of synthetic cases. A pooled calibration threshold allows false alerts to concentrate in particular backgrounds.

The archived grid checks, example-map markers, original summaries and uncertainty download use pooled thresholds. The uncertainty download resamples matched trial IDs jointly across candidates, frequencies and environments. Each bootstrap sample retains the planned proportion of central and outer targets. A difference is in percentage points.

Scenes

The main sweep contains 757,344 captured bursts per design: 161 carrier frequencies from 20 to 40 kHz in 125 Hz steps, seven received levels from −66 to −30 dBFS in 6 dB steps, 14 backgrounds and 48 matched trials per combination. Each design also receives 4,704 broadband bursts, 15,456 quiet-tone diagnostic frames, 3,584 healthy calibration frames and 3,584 held-out healthy frames.

Hardware and software controls

Hardware candidates use rotating Fourier storage with a full microphone tile and the single-tile read address simplified to the bin index. Area uses direct synthesis at 10 MHz in gscl45nm typical, in NAND2 gate equivalents. A passing RTL check compares the pipeline and two UART output maps with expected words. Timing and area are pre-layout. The 295k cutoff is a working logic budget.

The historical control uses the 30-mic, 10-bin, 256-sample configuration from revision 8b98329, with square-root Hann weighting and a 3° grid. Its archived area is from the historical mapping flow. The optimized candidates use Hann weighting. The 60-mic software reference uses the same 20 cm aperture, 512 samples (2.67 ms), Hann weighting, and every FFT bin centered inside 20–40 kHz. The 53 bin centers run from 20.25 to 39.75 kHz in 375 Hz steps. The reference uses floating-point steering and the same 1.5° scan grid as the finalists. It sees the same 16-bit input quantization. Its native geometry, capture and threshold can affect its score.
