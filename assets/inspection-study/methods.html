Methods and measurements

What counts as a pass?

The camera produces a power map. For this evaluation, software displays a hotspot only if it exceeds a threshold in absolute power. Each design gets its own threshold using the same rule: the 95th percentile (higher sample) of 144 target-absent calibration frames. The threshold stays fixed across every subsequent test.

A single-source pass requires a brightest pixel within 3° of the true direction on the sphere, above threshold, and at least 3 dB above the brightest pixel more than 9° away. Two-source tests require two distinct local peaks meeting the same angle and threshold rules, with the weaker peak clearing distant clutter by 3 dB. Frequency tests also require power at the nearest true-direction pixel to lie within 3 dB of that design’s matched all-bin floating-point power. This extra rule catches a quiet frequency gap even when a map points correctly.

Inspection scenes

  • Weak bursts. Eight random in-band components under a Gaussian envelope. Four carrier amplitude settings and three pulse widths, with random arrival times across a complete 1.33 ms window. Digital noise is present throughout. A burst falling outside a captured window is beyond this test.
  • Frequency coverage. Two independent scenes per tone at 125 Hz intervals from 20 to 40 kHz. Each candidate’s matched comparison uses the same layout, grid, window and PCM, with all in-band bins.
  • Environmental noise. 36 matched weak-burst scenes, each repeated with baseline microphone noise, added diffuse ultrasound, and a simulated gust. Five incoming ultrasonic waves approximate diffuse site noise. The gust combines partly correlated low-frequency pressure fluctuations from 130 to 2,900 Hz before PCM clipping and band selection. Gusts can overload the modeled input. Actual wind speed, analog microphone overload and the response of the enclosure are uncalibrated.
  • Drone interference. A front target competes with a rear near-field tone or multitone source at varying positions. Its level ranges from 6 dB below to 12 dB above the target. This is a geometric interference proxy. No recorded rotor spectrum is assumed.
  • Field of view. Off-grid targets at edges and corners within ±30° per axis. A clean edge score tests steering under this background level.
  • Two sources. Two independent in-band emitters at nominal separations of 6°, 12° and 18°, at equal level or with a 6 or 12 dB weaker neighbor. The task is to locate both sources. Discharge classification is outside the map test.

Map and model checks

Each candidate uses its configured window, bin list, angular grid, geometry and fixed-point arithmetic. Input conversion clips to 16-bit PCM. We count clipped input samples and internal clipping separately in the trial data. All three fixed-point models reproduced both stored baseline RTL map frames word for word. The scorer also passed controls for silence, wrong direction, a competing peak, two peaks, a missing second source and a flat map.

The fixed-point model also reproduced all 30 archived RTL output maps checked across the two new candidates and the earlier control, including weak frequency-gap and pulse fixtures for both new candidates. Map-word checks and hashes

The nine example scenes are selected by fixed trial index. Maps use the same absolute −82 to −35 dB power scale across scenes and designs. The burst in the quiet, diffuse-noise and gust examples is identical. These are synthetic post-decimation PCM simulations. Reproduce the benchmark

Use the pinned DFT-DAS source, Python 3.11 or newer, NumPy, SciPy and Matplotlib. From this study directory run python run_benchmark.py /path/to/DFT-DAS . followed by python make_plots.py bench. The bundled PCM inputs and actual RTL map words and fixture records allow the initial bit-exact check without a simulator installation.

Leaving the 24-bin point out of the 30-mic, 3° fit predicted 314.3k gates. Its measured 322.8k put the estimate 2.6% low. The displayed fit includes that measurement.

Why did 22 bins measure smaller than 21?

Both builds use 30 microphones and a 3° grid. Each bin has a rotating bank that brings the required microphone value to its front. All 30 microphones fit in one tile, so the read circuit only needs the bin index. The original RTL also calculates a tile offset from the microphone index. Valid microphone indices run from 0 through 29 and always give an offset of zero. The five-bit index also encodes 30 and 31. Synthesis kept selection logic for the more general address. Changing the bin count changed the binary offset for a second tile from 630 to 660, which let the tool eliminate different branches of the selector.

In the original mapped circuits, 374 spectrum positions fed combinational logic at 21 bins and 180 at 22 bins. Each position supplies 24 real bits and 24 imaginary bits. Adding a bin required 1,440 extra flip-flops, costing 6,120 gate equivalents. Combinational logic fell by 17,435.5 equivalents, so total area fell by 11,315.5.

For a controlled test we changed only the spectrum read address to use the bin index directly when all microphones fit in one tile. Both selectors then connected to 32 positions, the range of the five-bit bin index. The 21-bin build fell from 295,067 to 261,819 gate equivalents. The 22-bin build fell from 283,752 to 268,077. Each build reproduced its original 882 map words and cycle count in the two-map UART test. The gate plots use the original rotating-bank RTL throughout. Four synthesis measurements and map checks

At the 10 MHz mapping target, the simulated 40 / 16 and 30 / 22 designs used 10,462,498 and 10,467,568 clocks respectively for two complete UART maps. A linear clock conversion gives a replay rate. The current input handshake can pause microphone data, whereas a physical microphone continues to stream.

The timing results come from isolated candidate runs. Overlapping attempts on the 30-mic timing output were discarded and that candidate was rerun in a fresh directory. At fixed 40-mic / 16-bin settings, rotating full banks used 292,663.5 gates versus 396,584.75 with enabled rings, with identical output on the two-map check. Both published leading presets use full rotating banks with a captured sample per microphone. The repository’s default configuration still selects enabled rings.

For six 40-mic spectrum snapshots checked by the RTL scoreboard, we compared neighboring microphone words in each cyclic bank. One idle rotation would flip 15,260–15,566 spectrum bits out of 30,720, versus zero data-bit changes when enabled rings hold. This counts data transitions only.
